# ☕ Clasificador de Café con Lógica Difusa

Este proyecto implementa un sistema de inteligencia artificial basado en **lógica difusa (Fuzzy Logic)** para clasificar la **calidad del café** en tres categorías:

- Alta
- Media
- Baja

Utiliza los siguientes parámetros como entradas:

- **Acidez (pH)** entre 4.85 y 5.10
- **Contenido de Cafeína (%)** entre 1.0 y 2.5
- **Humedad (%)** entre 10 y 12
- **Aroma** (escala de 1 a 10)

---

## 🚀 Tecnologías utilizadas

- Python 3
- Flask (API y servidor web)
- Scikit-Fuzzy (lógica difusa)
- Matplotlib (gráficos)
- HTML5 + CSS (Frontend simple)
- Azure App Service (para despliegue)
- GitHub (control de versiones)
